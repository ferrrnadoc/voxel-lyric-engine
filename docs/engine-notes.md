# 引擎备注：API 速查和坑

文中的"第二节、第四节"等指 skill 的 SKILL.md 的章节。

## API 速查

**rail 镜头（默认）**：`Rail(路线点, t0, t1, look_ahead=6~7)`。路线是平滑曲线，时间到距离的映射 s(t) 严格递增，所以镜头不会停，也不会倒退。
- `rail.retime([...], dwell=None)`：每个场景一个锚点，让镜头在锚点物体打完字的那一刻到达设计好的阅读机位；阅读距离用 `at_pose(t, 物体位置, 机位点)` 从机位算（见模板）。快速穿过传送门时加两个锚点 `(t, 路线点, 0.01)` 定住穿过的时刻；`creep=[(ta, tb, 距离)]` 给一段慢爬。retime 只从上一个锚点往后找，锚点要按时间顺序排在路线上。不要给每个词都加锚点，也不要用 `dwell` 让每个词后面停一下。
- `rail.aim([(时刻, 取景点), ...], w=0.9, lead=0.6, hold=0.8, swing=0.9, release=1.5)`：每个场景（最多每个短语）一个取景。相邻取景平分中间的时间，到点的那一刻正好对准；间隔超过 `release` 秒时视线回到行进方向，穿过传送门、飞过地面字之后需要这样，否则镜头会回头看已经飞过的东西。
- `rail.steady(0.4)`：在 aim 之后、摆空中短语之前调用，把位置和视线方向平滑掉；之后 `place`、`project`、`at` 都用平滑后的镜头。
- `A, N, U = rail.place(短语中间时刻, sx, sy, dist)`：从镜头反推一个短语的中心，再用 `phrase_row` 排在这里（`tilt_to_travel=0.3` 让字面稍微转向镜头之后的位置）。
- 运镜类型就是路线形状：慢推是直线，环绕是绕着物体的弧，横移是和视线垂直的路线，后拉揭示是视线目标在前、路线往后退。roll 用 `Rail(..., roll=[(t, 角度), ...])`。

**排布**（`layout.py`）：先问"这个词长在哪个物体上"，字就沿那个物体的轮廓排。下表每一种都在测试场景里跑通过：

| 排布 | 用在哪 | 写法 |
|---|---|---|
| 环绕物体顶部 | 塔顶、柱子、蛋糕、钟面外圈 | `text_on_path(W, w, ArcPath(中心, 轴, 半径, start_deg, facing='out'), ...)` |
| 绕角色旋转的环 | around、orbit、头晕、被包围 | 同上，再加 `grp=W.group(lambda t: (rot(轴, 角速度 * t), 支点, (0, 0, 0)))` 整体旋转；转到正面时最好读 |
| 内壁螺旋 | 隧道、管道、旋转楼梯、vertigo | `ArcPath(..., facing='in', pitch=每圈升高, lean=25~35, lean_to=入口方向)`；不加 lean 时，从隧道里看几乎是侧面的一条线 |
| 印在球面上 | 地球仪、球、气球、星球 | `SpherePath(中心, 半径, lat_deg, start_deg, lift=0.25)` |
| 沿曲线 | 抛物线、河、飞行尾迹、绳子 | `PolyPath(点列)`；`lie=True` 让字平躺在地上，只适合镜头从侧面横移时看 |
| 路面标线堆叠 | follow、road、way、一路向前 | `path_stack(W, [(词, letter_t), ...], PolyPath(路), s起点, gap=3)`：每个词横躺在路上、字头朝前，镜头往前飞时按顺序读到 |
| 整行短语（普通词的默认排法） | 歌词密集段、一串短词、内心独白 | `phrase_row(W, [(词, letter_t, letter_tout, {}), ...], 中心, N, U)`：一个短语先排成一行，再逐词打出；飘在空中时，中心用 `rail.place(短语中间时刻, sx, sy, 10~13)` |
| 贴面平铺 | 招牌、墙、屏幕、纸面 | `word_flat` / `text3d` |

所有排布都接受 `letter_t`（打字）和 `letter_tout`（删字），并登记到 `W.words` 供 readcheck 检查。

**出字**：模板的 `typed(li, wi)` = `syllable_times` + `type_letters`，约每秒 14 个字母，起点是起唱前 0.04 秒；把 `lrc_words.vocal_onsets` 或 `pitchseg.py` 的音符起点作为 `onsets` 传给 `syllable_times`，音节块会吸附到真实的起音上。删字用 `untype_letters(词, t)`，约每秒 16 个字母。模板的 `phrase_groups`（按换气拆短语）、`hero_index`（按最长的音选主角词）、`visible_later`（往后看 4 秒判断字还在不在画面里，因为镜头之后可能转回来）都是默认做法，可以手改。

**vox2**（story 里依次 `from kit import *`、`from vox2 import *`、`from layout import *`）：
- `text3d` / `mask_points` 加 `font_name`、`px`（12–18）、`wght` 把字体栅格化成方块；`mask_points` 返回每个像素的位置、字母序号和列号，按列号递增 `t_in` 就是逐笔书写；先放灰色版、唱到时叠一份 `emit=True` 的就是点亮。
- `anim='move', off=(dx,dy,dz), md=秒, arch=高度`：方块从别处飞来（聚拢、升起、落叶拼字、打水漂）。`W.group(fn)`：fn(t) 返回 (旋转矩阵, 支点, 位移)，用于翻页、旋转的吊牌、开动的车、钟的指针、绕人旋转的字环。`build=0.2~0.6`：道具一块一块搭出来。
- 质感只来自方块颜色（两三种相近色混用）、厚度（凸起或凹陷，背后加一层深色）、发光（`emit` / `glow`）和排列（分开的灯珠、沿路面拉长的喷字）。
- Step 0 下载的字体举例：烫金衬线 Cinzel，圆体 Fredoka、Nunito，积木字 Bungee，像素窄体 VT323，窄黑体 Bebas Neue、Oswald，球衣 Jersey 15，刷字 Caveat Brush，哥特体 Jacquarda Bastarda，打字机 Courier Prime，像素原生 Silkscreen、Pixelify Sans。细笔画字体在低 px 下会断笔：可变字体用 `wght=700–900`，或者换像素原生字体。

**氛围**：`Sky([(t, 顶色, 底色, 星星0~1, 环境光0~1), …])`；`particles(W, 中心, (宽, 高, 深), t0, t1, rate=5~8, shapes=(HEART_S, SPARK_S, CROSS_S), cols=(...))`；`render(..., mblur=(7, 0.5, 60))` 给快速运镜加运动模糊（画面流速超过 60 °/秒 的帧最多用 7 个子帧平均，渲染时间也成倍增加；子帧太少细字会重影；`mblur=None` 关掉）。方块崩散重组：按离某点的距离错开每个方块的 `t_out` / `t_in`（还没在成片里验证过，第一次用要多看几轮预览）。

**camcheck**：`python3 story.py --camcheck` 打印四张表：VIOLENT（第二节的上限表）；readcheck（每个词打完时的屏幕位置、大小、偏角和可读时长，标 OFF-CENTRE / SMALL / BIG / OBLIQUE / SHORT，片尾被裁掉的词标 SHORT 可以不管）；stallcheck（流速分布和参考片对比，标 STALL）；steadycheck（画面运动方向的反转次数和急转比例，抓"像手持、发晕"，标 HANDHELD）。后三张是诊断。From The Start 第 3 版（见 evidence.md）实测：流速 12/17/24/51 °/秒，反转每 10 秒 5.4 次，0 次 VIOLENT。

## 坑

- 坐标系：y 轴朝上。`N` 是文字或图标正面朝向的方向（指向观众），`U` 是它的上方，`R = U × N`。墙面朝 -x 时，`N=(-1,0,0)`、`U=(0,1,0)`。
- 人物只支持四个朝向（`+z/-z/+x/-x`）。渲染器现在能画转过角度的方块（`W.add(M=...)`，沿路径排的字就是这样做的），但人物和道具仍按轴对齐来搭；想要倾斜的东西用 `tilt`，或者用 `W.group` 整体旋转。
- 面数在 6 万左右时依然很快。大面积地形用 1 格的方块，不要把地面铺得太远（雾在 35–85 格之间）。
- 夜景会被环境光压暗：歌词和歌词载体要设 `glow=True`，路灯这类发光体设 `emit=True`。
- 中文歌词用 `fpath=CJK, px=14`；逐字入场时把每个字当成一个"词"。
- 截取歌曲中段时：`lrc_words.py --start S --end E`，渲染时设 `audio_offset=S`。words.json 里的时间都是相对于 S 的。
- 快歌（超过 130 BPM）：`type_letters` 会把每个词压缩到下一个词开唱之前打完，所以不再需要合并短语（旧模板的 `phrases()` 已经删掉）。转场时间压到 0.4–0.6 秒。鼓点重的副歌想让镜头每拍轻推一下，只有旧的 `Camera(keys, bumps=...)` 支持。
- librosa 测出的 tempo 可能偏 4/3 倍或 2 倍。比如《Lover Girl》被测成 117 BPM，实际约 88 BPM。选歌、定转场节奏都要按人工核对过的速度来。
- 移动的小物件（抛出的钥匙、被击飞的球）最简单的做法是翻页动画：沿轨迹放 15–20 份副本，每份 `anim='none'`，只在自己的时间窗内出现。缩出的 0.16 秒会留下一点拖影，正好像动态模糊。也可以用 vox2 的 `W.group(fn)`：整个物体跟着 fn(t) 返回的旋转和位移走，省方块。
- 路面字沿视线方向拉长来抵消透视时：拉长倍数约为 `sqrt(h²+d²)/h`（h 是镜头离地高度，d 是水平距离，上限 3.4）；每个像素沿拉长方向补 `ceil(倍数)` 个方块，否则拉开后全是缝；道路窄就一个词占一行。
- 可变字体（文件名带 `[wght]`）用 `wght=` 选字重。`from kit import *` 要写在 `from vox2 import *` 前面，否则 kit 带进来的旧 `text3d` 会盖掉 vox2 的。
- `--preview` 的帧号是 `round(t*30)`，拼联系表找文件时用同样的取整。长镜头看得很远时，渲染时把 `far=150, fog=(50, 140)` 调大。
- 沿路径排的字（`layout.py`）每个字母都是转过角度的方块：`W.add(..., M=朝向矩阵, gk=网格键)`。只有带 gk 的旋转方块才会剔除相邻的隐藏面；自己用 `M=` 搭东西时也要给 gk，否则面数会翻好几倍。
- `rail.retime` 报 "anchors must strictly increase"：说明有两个词在路线上的先后和唱的先后相反。改物体摆放或路线点，不要改时间。
- `rail.place` 摆出来的词不知道场景里有什么，可能插进墙里或树里：看预览，挪 sx/sy 或 dist。
- 切音节靠 pyphen（`pip install pyphen`），没装时退回按元音分组的粗略切法。中文逐字入场时，每个字就是一个音节块。
- 测试场景（12 秒、占位词）：塔顶环绕、隧道螺旋、绕人旋转环、路面标线、跟镜头阶梯、球面 hero，readcheck 0 处标记、0 次 VIOLENT，词的停留中位数 1.15 秒。
- 两个角色同框时，间距不要超过约 3 格，否则在阅读距离上两人头顶的字会分到画面两边。墙面上的字比一个画面还宽时，镜头沿墙按阅读顺序平移，不要硬塞进一个画面。
- 静态字体（文件名不带 `[wght]`）会忽略 `wght` 参数，可以和可变字体混在同一个 `phrase_row` 里。
- 字贴在大方块载体上时，要离开载体表面至少 0.15–0.25（载体方块越大、镜头越斜，就要离得越远），否则画家算法按面中心排序，载体的大面会盖住部分笔画。平铺在 1 格地砖上的字（路面喷字、草坪字、落叶字、贴纸）只抬高不够，近看会被地砖顶面一条条盖断；用 `W.add(..., bias=0.5~0.8)` 让它们晚画，抬高 0.03 就够。
- 路线离墙、柱、招牌至少 1.5 格，否则近裁剪面会把它们切成大色块。招牌可以架在路线上方做龙门架（模板的做法），或者放在路边、内侧边离路线 1.6 格以上。隧道壁上的字要向入口方向倾斜（`ArcPath(lean=30, lean_to=入口方向)`），不然从隧道里看几乎是侧面的一条线。
- 用传送门转场时，把下一场摆在这一场的入口道具后面，镜头才是真的穿过去。
- 放在行进方向正前方的空中短语会被镜头一路逼近、越变越大：dist 放到 10–13 格并相应放大字，或者放在画面流过来的那一侧。
- 估算字号时注意：`height` 是整行高度（含上下留白），大写字母只占 55–60%，小写 x-height 约占 35%；readcheck 会直接算出每个词的实际占比。主角词太长放不下时，加宽载体，而不是缩小字。
- 斜着看一块平面招牌时，近的一侧显得更大，招牌看起来会偏离画面中心。这不是 bug，想让它显得居中就把镜头放正一些。
- 旧的关键帧镜头 `Camera(keys)` 每到一个关键帧都会减速再加速；look 目标在两个关键帧之间跳几十格会让视线先反甩一下，快速移动后马上停住会冲过头。只在需要鼓点推镜（`bumps`）时用它。
